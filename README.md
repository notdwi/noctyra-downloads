# Noctyra para Android

Downloads oficiais do aplicativo Noctyra.

**[Baixar APK mais recente](https://github.com/notdwi/noctyra-downloads/releases/latest/download/app-release.apk)** · [Todas as versões](https://github.com/notdwi/noctyra-downloads/releases) · [Comunidade no Discord](https://discord.gg/RrGqMjrm8K)

## Instalação

Requer Android 8.0 ou superior. Baixe o APK, abra o arquivo no aparelho e siga as instruções do Android. Se solicitado, permita a instalação pelo navegador ou gerenciador de arquivos que estiver usando.

## Sobre este repositório

Este repositório contém somente APKs, checksums e notas de versão. O código-fonte do aplicativo é mantido separadamente.

## Integridade

Cada release inclui um arquivo `SHA256SUMS.txt` para conferir a integridade do APK baixado.

## Conteúdo

O Noctyra não hospeda vídeos. O conteúdo é disponibilizado por serviços de terceiros.
